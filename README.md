## เริ่มทดสอบครั้งแรก

สำหรับคุณครูที่เพิ่งเริ่มใช้ ให้ทำตามลำดับนี้ก่อน

1. ขอ **รหัสเชิญ** จากผู้ดูแล หากมีบัญชีอยู่แล้ว ให้ขอชื่อบัญชีและใช้รหัสผ่านของตนเอง
2. เปิดเว็บจากคอมพิวเตอร์หรือโน้ตบุ๊ก แนะนำให้ใช้หน้าจอขนาดใหญ่สำหรับกรอกคะแนนทั้งห้อง
3. สมัครหรือเข้าสู่ระบบ แล้วจดชื่อบัญชีที่ระบบแสดงไว้ในที่ส่วนตัว
4. แจ้งผู้ดูแลว่าเป็นครูรายวิชาใด หรือครูประจำชั้นห้องใด ผู้ดูแลต้องมอบหมายสิทธิ์ก่อน
5. เลือก **ภาคเรียน** ที่มุมขวาบน และตรวจว่ารายวิชา ห้อง และรายชื่อนักเรียนถูกต้อง
6. เริ่มจากค้นหานักเรียนและเปิดโปรไฟล์เพื่อดูข้อมูล หากต้องการทดลองกรอก ให้ผู้ดูแลเตรียมนักเรียนและวิชาจำลองแยกไว้ ไม่ใช้คะแนนจริงทดลอง
7. ทดลองกรอกคะแนน → **บันทึก** → ตรวจผล หยุดตรงขั้นตอนนี้ได้ ยังไม่จำเป็นต้องประกาศ
8. เมื่อตรวจถูกต้องและได้รับอนุญาต จึงลอง **ประกาศผล** และส่งออก Excel

**จำไว้ 3 ข้อ:** เลือกเทอมให้ถูก · กดบันทึกก่อนออกจากหน้า · อ่านขอบเขตก่อนกดล้างหรือลบ

## สิทธิ์ครูกับผู้ดูแลต่างกันอย่างไร

| งาน                                   | ครูรายวิชา                 | ครูประจำชั้น                   | ผู้ดูแล             |
| ------------------------------------- | -------------------------- | ------------------------------ | ------------------- |
| ดูนักเรียนและเกรด                     | เฉพาะวิชาที่มอบหมาย        | ทุกวิชาในห้องและเทอมที่มอบหมาย | ทั้งโรงเรียน        |
| แก้ชื่อ รหัส และข้อมูลนักเรียน        | นักเรียนที่มีสิทธิ์เข้าถึง | นักเรียนในห้องที่ดูแล          | ทั้งโรงเรียน        |
| เพิ่มนักเรียน นำเข้ารายชื่อ และลบถาวร | ไม่มีสิทธิ์จัดการส่วนกลาง  | ไม่มีสิทธิ์จัดการส่วนกลาง      | ทำได้               |
| สร้างเทอม ห้อง วิชา และเกณฑ์          | ไม่มีเมนูส่วนกลาง          | ไม่มีเมนูส่วนกลาง              | ทำได้               |
| เชิญครู มอบหมายงาน และจัดการบัญชีครู  | ทำไม่ได้                   | ทำไม่ได้                       | ทำได้               |
| เปลี่ยนโหมดสว่าง/มืด/ตามระบบ          | ทำได้บนเครื่องตนเอง        | ทำได้บนเครื่องตนเอง            | ทำได้บนเครื่องตนเอง |
| เปลี่ยนสีและข้อมูลโรงเรียน            | ทำไม่ได้                   | ทำไม่ได้                       | ทำได้               |

**สิทธิ์แก้ไขเกรด:** ครูรายวิชาและครูประจำชั้นกรอก แก้ ประกาศ ยกเลิกประกาศ หรือล้างเกรดได้เฉพาะวิชาที่ได้รับมอบหมายให้สอน สิทธิ์ครูประจำชั้นทำให้ดูทุกวิชาในห้องได้ ครูที่มีสิทธิ์เข้าถึงนักเรียนในเทอม/ห้องที่มอบหมายสามารถตั้งหรือเปลี่ยน PIN รายคนจากโปรไฟล์นักเรียนได้

ครูประจำชั้นยังเป็นบัญชีครู ไม่ได้กลายเป็นผู้ดูแลทั้งโรงเรียน ผู้ดูแลสามารถให้สิทธิ์ครูรายวิชาและครูประจำชั้นร่วมกันได้ เมนูที่เห็นจึงอาจต่างกันในแต่ละบัญชี

## สมัครบัญชีและเข้าสู่ระบบ

### กรณียังไม่มีบัญชีครู

1. ขอรหัสเชิญที่ยังใช้งานได้จากผู้ดูแล
2. ที่หน้าเข้าสู่ระบบ กด **สมัครบัญชีครู**
3. กรอกชื่อและนามสกุลภาษาไทยในช่องที่ระบุ **ภาษาไทย**
4. กรอกชื่อและนามสกุลภาษาอังกฤษในช่องที่ระบุ **ภาษาอังกฤษ** ระบบใช้ส่วนนี้สร้างชื่อบัญชี
5. ตั้งรหัสผ่านตามข้อกำหนดที่แสดง และกรอกรหัสเชิญ
6. ตรวจชื่อทางการให้ถูกต้อง และอ่าน/ยืนยันข้อความก่อนสมัคร ชื่อทางการแก้เองจากโปรไฟล์ไม่ได้ หากผิดต้องติดต่อผู้ดูแล
7. เมื่อสมัครสำเร็จ ระบบแสดง **ชื่อบัญชีสำหรับเข้าสู่ระบบ** เก็บชื่อบัญชีนี้ไว้ ไม่จำเป็นต้องมีกล่องรับอีเมลที่ชื่อนั้น
8. กด **เข้าสู่ระบบและตั้งค่าโปรไฟล์** แล้วระบุวิชาและห้องที่สอน เพื่อให้ผู้ดูแลมอบหมายงาน

หากยังไม่เห็นนักเรียนหรือรายวิชาหลังสมัคร ไม่ได้หมายความว่าบัญชีเสีย ผู้ดูแลต้องมอบหมายสิทธิ์ก่อน

### กรณีมีบัญชีแล้ว

1. เปิดหน้าเข้าสู่ระบบและเลือก **ครู / ผู้ดูแล**
2. กรอกชื่อบัญชีในช่องอีเมล และรหัสผ่านของตนเอง
3. กดรูป **ลูกตา** เพื่อแสดงหรือซ่อนรหัสผ่านได้ รูปนี้ไม่ใช่ปุ่มส่งแบบฟอร์ม
4. กด **เข้าสู่ระบบ**
5. เมื่อใช้คอมพิวเตอร์ร่วมกับคนอื่น ให้กด **ออกจากระบบ** ที่ด้านล่างเมนูเมื่อเสร็จ ไม่ใช่เพียงปิดแท็บ

หากลืมรหัสผ่าน ให้ติดต่อผู้ดูแล ระบบเบต้ายังไม่มีหน้ากู้รหัสผ่านด้วยตนเอง

## รู้จักส่วนต่าง ๆ ของหน้าจอ

- **แถบด้านบน:** ชื่อหน้าที่เปิดอยู่ ตัวเลือกภาคเรียน ภาษา และวัน/เวลาไทย ผู้ดูแลมีปุ่มเชิญครูเพิ่มเติม
- **ภาคเรียน:** เป็นบริบทของห้อง รายวิชา คะแนน และ GPA ตรวจให้ถูกทุกครั้งก่อนเริ่มงาน ภาษาไทยแสดงปี พ.ศ. ภาษาอังกฤษแสดงปี ค.ศ.
- **สถานะออนไลน์ตรงรูปโปรไฟล์ด้านล่าง:** แสดงการเชื่อมต่อเครือข่ายของเครื่อง ไม่ใช่การยืนยันว่าคะแนนถูกบันทึกแล้ว
- **เมนูด้านซ้าย:** งานสอน ทะเบียนการเรียน ดูแลโรงเรียน และตั้งค่า/ช่วยเหลือ ส่วนของผู้ดูแลจะแสดงเฉพาะบัญชีที่มีสิทธิ์
- **ย่อเมนู:** กดปุ่มย่อ/ขยายด้านบนของเมนูเพื่อเพิ่มพื้นที่ เมื่อย่อแล้ว วางเมาส์ที่ไอคอนจะเห็นชื่อเมนู
- **โปรไฟล์ของฉัน:** กดรูปหรือชื่อของตนเองที่ด้านล่างเมนู ไม่มีรายการโปรไฟล์แยกในเมนูหลัก
- **ตัวเลือกแบบเปิดรายการ:** กดเพื่อเปิด ใช้ลูกศรบน/ล่างเพื่อเลื่อน Enter เพื่อเลือก และ Escape เพื่อปิด รายการยาวสามารถเลื่อนได้
- **ปุ่มสีจาง:** มักหมายถึงยังไม่มีข้อมูลที่ต้องบันทึก กำลังทำงาน หรือรายการนั้นยังไม่อนุญาตให้แก้

## คู่มือสำหรับครู

### 1. เริ่มจากหน้าภาพรวม

1. เลือกภาคเรียนด้านบน
2. ดูรายวิชาของคุณ แต่ละรายการระบุวิชา ห้อง จำนวนคนที่กรอกแล้ว และจำนวนที่ประกาศแล้ว
3. ใช้ตัวกรอง **ทั้งหมด / ยังไม่ครบ / กรอกครบแล้ว** เพื่อเลือกงาน
4. กดรายการวิชาเพื่อเข้าสู่หน้ากรอกคะแนนของห้องนั้น

จำนวนที่กรอกครบกับจำนวนที่ประกาศแล้วเป็นคนละเรื่อง กรอกครบแล้วอาจยังเป็นฉบับร่างทั้งหมดได้

### 2. ค้นหาและตรวจข้อมูลนักเรียน

1. เปิดเมนู **นักเรียน**
2. พิมพ์ชื่อหรือรหัสในช่องค้นหา หรือเลือกห้องเรียน
3. รายชื่อเรียงตามห้องเป็นหลัก เปลี่ยนการเรียงตามรหัสหรือชื่อได้
4. หากมีหลายหน้า ใช้ปุ่มก่อนหน้า/ถัดไปของตาราง
5. กดชื่อนักเรียนหรือ **โปรไฟล์ / กรอกเกรด** เพื่อเปิดข้อมูลและคะแนนของคนนั้น

รหัสนักเรียนเป็นข้อความ เช่น `00001` เป็นเพียงตัวอย่าง อย่าตัดเลขศูนย์ด้านหน้าออก

### 3. แก้ข้อมูลนักเรียน

1. ในรายชื่อ กด **แก้ไข** หรือเปิดโปรไฟล์แล้วกด **แก้ไขข้อมูลนักเรียน**
2. ตรวจชื่อ นามสกุล รหัส เลขที่ และห้องในเทอมที่เลือก
3. แก้เฉพาะข้อมูลที่ต้องการ แล้วกด **บันทึกการเปลี่ยนแปลง**
4. ตรวจรายชื่อหรือโปรไฟล์อีกครั้งว่าแสดงค่าที่แก้แล้ว

**ชื่อและรหัส** เป็นข้อมูลกลางของนักเรียน จึงมีผลกับทุกเทอม ส่วน **ห้องและเลขที่** เป็นข้อมูลของเทอมที่เลือก

การย้ายห้องของนักเรียนที่มีเกรดต้องจัดการอย่างระมัดระวัง อาจต้องให้ผู้ดูแลยืนยันล้างเกรดของเทอมนี้ก่อน และต้องมีสิทธิ์ในห้องปลายทาง อย่าติ๊กยืนยันล้างเกรดเพียงเพื่อทดลองย้ายห้อง

### 4. กรอกคะแนนตามรายวิชา — เหมาะกับการกรอกทั้งห้อง

1. เปิด **บันทึกผลการเรียน** และเลือกเทอมให้ถูก
2. กดส่วนเลือกวิชา แล้วค้นหาชื่อวิชา รหัสวิชา หรือห้องเรียน
3. เลือกวิชาและห้องที่ต้องการ ตรวจหัวตารางและคะแนนเต็ม
4. กรอกคะแนนทีละคน ระบบแสดงเกรดตัวอย่างตามเกณฑ์ของวิชานั้น
5. กด **Enter** เพื่อไปช่องถัดไป หรือ **Shift + Enter** เพื่อย้อนกลับ ใช้ **Tab** ได้เช่นกัน
6. กด **บันทึกผลฉบับร่าง** แล้วรอข้อความยืนยัน ก่อนเปลี่ยนวิชาหรือออกจากหน้า
7. ตรวจคะแนนอีกครั้ง แล้วจึงกด **ประกาศผลที่บันทึกแล้ว** เมื่อพร้อม

- **ช่องว่าง** หมายถึงยังไม่กรอก ไม่ใช่คะแนน 0
- **0** หมายถึงกรอกคะแนนศูนย์จริง และอาจมีผลต่อ GPA เมื่อประกาศแล้ว
- วิชาแบบ **ผ่าน/ไม่ผ่าน** อาจใช้คะแนนคำนวณอัตโนมัติ หรือให้เลือกผ่าน/ไม่ผ่านด้วยตนเอง ขึ้นอยู่กับที่ผู้ดูแลตั้งไว้
- ข้อมูลที่ยังไม่ได้บันทึกไม่ติดไปกับการประกาศ ต้องบันทึกก่อนเสมอ

### 5. กรอกตามนักเรียน — เหมาะกับครูประจำชั้น

1. เปิด **นักเรียน** แล้วกดชื่อหรือ **โปรไฟล์ / กรอกเกรด**
2. ตรวจชื่อนักเรียน รหัส ห้อง และเทอมก่อนกรอก
3. กรอกแต่ละรายวิชาที่แสดงในหน้าเดียว
4. กด **บันทึกทุกวิชา** เพื่อบันทึกเฉพาะค่าที่แก้ไข
5. ตรวจผล หากต้องการประกาศ ใช้ปุ่มประกาศผลที่บันทึกแล้วและอ่านกล่องยืนยัน
6. กด **นักเรียนคนถัดไป** หรือ **คนก่อนหน้า** เพื่อทำงานต่อในห้องเดียวกัน โดยไม่ต้องกลับไปรายชื่อ

ครูรายวิชาเห็นเฉพาะวิชาที่ได้รับมอบหมาย ครูประจำชั้นเห็นทุกวิชาของห้องที่ดูแลในเทอมนั้น ปุ่มก่อนหน้า/ถัดไปจะไม่ให้กดเมื่อถึงต้นหรือท้ายรายการ

### 6. บันทึก ประกาศ ยกเลิกประกาศ และล้างเกรด

| ปุ่ม/สถานะ     | ความหมาย                                              | ใช้เมื่อใด                       |
| -------------- | ----------------------------------------------------- | -------------------------------- |
| บันทึก         | เก็บคะแนนเป็นฉบับร่าง ยังไม่ใช่การประกาศ              | กรอกหรือแก้คะแนนเสร็จ            |
| ประกาศผล       | เปลี่ยนผลที่บันทึกแล้วเป็นผลประกาศ และล็อกการแก้คะแนน | ตรวจข้อมูลถูกต้องแล้ว            |
| ยกเลิกประกาศผล | เปิดให้แก้คะแนนเดิมได้ ไม่ใช่ลบคะแนน                  | ต้องแก้ผลที่ประกาศแล้ว           |
| ล้างเกรด       | ลบผลในขอบเขตที่แสดง รวมผลที่ประกาศแล้ว ต้องกรอกใหม่   | ต้องการเริ่มกรอกผลนั้นใหม่จริง ๆ |

**วิธีแก้คะแนนที่ประกาศผิด:** ยกเลิกประกาศ → แก้คะแนน → บันทึก → ตรวจผล → ประกาศใหม่

**ขอบเขตการล้าง:** ในโปรไฟล์นักเรียน ล้างหนึ่งวิชาของนักเรียนคนนั้น ในหน้ากรอกตามรายวิชา ล้างวิชาที่เลือกทั้งห้อง อ่านกล่องยืนยันทุกครั้ง การล้างไม่ใช่การย้อนกลับและกู้คืนจากปุ่มในเว็บไม่ได้

หากแจ้งว่าข้อมูลเปลี่ยนโดยผู้ใช้อื่น ให้โหลดข้อมูลใหม่ก่อนกรอกต่อ อย่าบันทึกทับซ้ำโดยไม่ตรวจ เพราะอาจมีครูอีกคนแก้หรือประกาศผลไปแล้ว

### 7. ดู GPA และส่งออก Excel

1. เปิด **นักเรียน** และเลือกภาคเรียน/ห้องที่ต้องการ
2. ดูคอลัมน์ **เกรดเฉลี่ย** ได้ทันที หรือเปิดโปรไฟล์เพื่อดู GPA และรายละเอียดรายวิชา
3. กด **ส่งออก Excel** เพื่อดาวน์โหลดรายชื่อที่ตรงกับตัวกรอง พร้อม GPA
4. เปิดไฟล์แล้วตรวจรหัส ชื่อ ห้อง เลขที่ และ GPA ก่อนส่งต่อ

GPA คำนวณเฉพาะผล **ที่ประกาศแล้ว** ของวิชาเกรดตัวเลข ซึ่งตั้งให้รวม GPA และมีหน่วยกิตมากกว่า 0 ในเทอม/ห้องที่เลือก โดยถ่วงน้ำหนักตามหน่วยกิต

- ไม่นับผลฉบับร่าง วิชาผ่าน/ไม่ผ่าน วิชาที่ไม่รวม GPA หรือหน่วยกิตเป็น 0/ยังไม่ระบุ
- ถ้ายังไม่มีผลที่ใช้คำนวณ แสดง `—` บนเว็บ และช่องว่างใน Excel
- GPA ของบัญชีครูรายวิชาอาจใช้เฉพาะวิชาที่ครูมีสิทธิ์ดู จึงไม่จำเป็นต้องเท่ากับ GPA ทั้งห้องของครูประจำชั้น/ผู้ดูแล
- Excel เก็บ GPA เป็นตัวเลขทศนิยม 2 ตำแหน่ง และรหัสนักเรียนเป็นข้อความเพื่อรักษาเลขศูนย์ด้านหน้า
- การส่งออกไม่ใช่การสำรองฐานข้อมูลทั้งหมด เก็บไฟล์ผลการเรียนในที่ส่วนตัว ไม่อัปโหลดเข้า GitHub หรือพื้นที่สาธารณะ

### 8. เปลี่ยนรูปและแก้โปรไฟล์ของตนเอง

1. กดรูปหรือชื่อของตนเองที่ด้านล่างเมนู
2. คลิกรูปโปรไฟล์เพื่อเลือกรูป **JPG / PNG / WebP ขนาดไม่เกิน 2 MB**
3. รูปบันทึกทันทีเมื่ออัปโหลดสำเร็จ
4. แก้ชื่อเล่น ข้อมูลติดต่อ ข้อมูลการสอน หรือข้อความเกี่ยวกับตนเอง แล้วกดบันทึกสำหรับข้อมูลส่วนนี้
5. หากชื่อทางการผิดหรือบัญชีเดิมยังไม่มีชื่อไทย ให้ติดต่อผู้ดูแล

การระบุวิชาและห้องในโปรไฟล์เป็นข้อมูลให้ผู้ดูแลพิจารณา ไม่ใช่การมอบหมายสิทธิ์ให้ตนเอง

### 9. ภาษา หน้าตา และการแจ้งปัญหา

- เปลี่ยน **ไทย / English** จากแถบด้านบน
- เปิด **การตั้งค่า → การแสดงผล** เพื่อเลือกสว่าง มืด หรือตามระบบ มีผลกับเครื่องที่กำลังใช้
- เลือก **แจ้งปัญหา / เสนอแนะ** ระบุหน้าที่ใช้งาน สิ่งที่ทำ และสิ่งที่คาดว่าจะเกิด
- ไม่ส่งรหัสผ่าน รหัสเชิญที่ยังใช้ได้ หรือข้อมูลนักเรียนจริงลงพื้นที่สาธารณะ หากต้องแนบตัวอย่าง ให้ผู้ดูแลช่วยปิดชื่อ/รหัส/รูปก่อน

## คู่มือสำหรับผู้ดูแล

ผู้ดูแลใช้ขั้นตอนกรอกเกรดในคู่มือครูได้ทั้งหมด ส่วนต่อไปนี้เป็นการเตรียมและจัดการระบบส่วนกลาง

### 1. เตรียมโรงเรียนตามลำดับ

1. ตั้งค่าข้อมูลโรงเรียนและภาษาที่ต้องการ
2. เตรียมเกณฑ์การตัดเกรด
3. สร้างภาคเรียนและห้องเรียน
4. เพิ่มหรือนำเข้ารายชื่อนักเรียนในเทอม/ห้องที่ถูกต้อง
5. เพิ่มวิชาที่เปิดสอน พร้อมหน่วยกิตและรูปแบบการให้ผล
6. เชิญครูสมัคร แล้วมอบหมายรายวิชาหรือห้องประจำชั้น
7. ให้ครูตรวจรายชื่อและทดลองกับข้อมูลจำลองก่อนกรอกข้อมูลจริง

ถ้าระบบมีข้อมูลอยู่แล้ว ให้ตรวจและใช้ข้อมูลเดิมก่อน ไม่จำเป็นต้องเพิ่มซ้ำหรือล้างระบบเพื่อเริ่มทดสอบ

### 2. ตั้งค่าข้อมูลโรงเรียนและธีม

1. เปิด **การตั้งค่า**
2. ส่วน **การแสดงผล** เลือกโหมดของเครื่องตนเอง
3. ส่วน **Theme และสีของโรงเรียน** เลือกชุดสี หรือปรับสีหลัก สีรอง พื้นหลังสว่าง และพื้นหลังมืด
4. เมื่อปรับสีเอง ป้ายชุดสีเปลี่ยนเป็น **Custom**
5. ตรวจส่วน **ข้อมูลโรงเรียน** เช่น ชื่อ ชื่อย่อ โดเมนบัญชี และโลโก้ตามช่องที่มี
6. ตรวจ **ค่าเริ่มต้นการเรียน** เช่น ภาษาเริ่มต้นและเกณฑ์การตัดเกรด
7. กรอก **ติดต่อและช่วยเหลือ** หากต้องการ แล้วกดบันทึก

สีโรงเรียนใช้ร่วมกันทั้งระบบ แต่โหมดสว่าง/มืดใช้กับเครื่องแต่ละเครื่อง การเปลี่ยนโดเมนบัญชีมีผลกับบัญชีที่สมัครใหม่ ไม่เปลี่ยนชื่อบัญชีเดิม และไม่ได้สร้างกล่องรับอีเมลจริง

### 3. สร้างหรือเลือกภาคเรียน

1. เปิด **ภาคเรียน** แล้วกดเพิ่ม
2. กรอกปีการศึกษาและชื่อภาคเรียนให้ชัดเจน เช่น ภาคเรียนที่ 1
3. เลือกสถานะใช้งานตามที่ต้องการ แล้วบันทึก
4. เลือกภาคเรียนนั้นที่แถบด้านบนก่อนเพิ่มนักเรียน เปิดวิชา หรือมอบหมายห้องประจำชั้น

อย่าสร้างเทอมซ้ำเพื่อแก้ชื่อ หากยังแก้ได้ให้ใช้ปุ่มแก้ไข หากรายการถูกล็อกเพราะมีข้อมูลใช้งาน ให้ตรวจความสัมพันธ์ก่อนดำเนินการ

### 4. สร้างห้องและเพิ่มนักเรียน

**สร้างห้อง:** เปิด **ห้องเรียน → เพิ่ม** กรอกชื่อ เช่น `ม.1/1` เลือกสถานะและบันทึก

**เพิ่มนักเรียนทีละคน:**

1. เลือกภาคเรียนด้านบน
2. เปิด **นักเรียน → เพิ่มนักเรียน**
3. กรอกรหัส ชื่อ นามสกุล ห้อง และเลขที่ตามข้อมูลที่มี
4. รหัสต้องไม่ซ้ำ และรักษาเลขศูนย์ด้านหน้า
5. ไม่จำเป็นต้องตั้ง PIN สำหรับการทดสอบครู เพราะเบต้ายังปิดให้นักเรียนเข้าใช้
6. กดบันทึกและตรวจว่ารายชื่ออยู่ในห้อง/เทอมที่เลือก

ไม่จำเป็นต้องนำที่อยู่ บ้าน เบอร์โทรของนักเรียน หรือเลขบัตรประชาชนเต็มเข้าสู่ระบบเพื่อใช้จัดการเกรด

### 5. นำเข้ารายชื่อจาก Excel

1. เตรียมห้องและเลือกเทอมให้ถูก
2. เปิด **นำเข้านักเรียน** หรือกด **นำเข้า Excel** ในหน้านักเรียน
3. ถ้ายังไม่มีรูปแบบไฟล์ กดดาวน์โหลดไฟล์ตัวอย่าง
4. เลือกไฟล์ ระบบพยายามจับคู่คอลัมน์ เช่น รหัส เลขที่ ชื่อ นามสกุล และห้องอัตโนมัติ
5. หากไม่มีคอลัมน์ห้อง ให้เลือกห้องเดียวสำหรับไฟล์ หรือแก้การจับคู่คอลัมน์ตามที่หน้าจอแสดง
6. ตรวจตัวอย่าง จำนวนรายการพร้อมนำเข้า และข้อผิดพลาดก่อนยืนยัน
7. แก้รหัสซ้ำ ช่องที่ขาด หรือค่าที่ไม่ถูกต้อง ตรวจเลขศูนย์ด้านหน้ารหัสด้วย
8. กดนำเข้าเฉพาะรายการที่ผ่านการตรวจ และยืนยันจำนวนตามกล่องแจ้ง
9. กลับไปหน้ารายชื่อ เลือกห้อง แล้วตรวจผล

ขั้นตอนตรวจตัวอย่างยังไม่บันทึกข้อมูล การนำเข้าจริงเกิดหลังยืนยัน อย่านำเข้าไฟล์เดิมซ้ำเพื่อทดลองกับข้อมูลจริง

### 6. สร้างวิชาและเปิดสอนหลายห้องในครั้งเดียว

**ทะเบียนวิชา** เก็บรหัสและชื่อกลาง ส่วน **วิชาที่เปิดสอน** ระบุว่าวิชานั้นเปิดในเทอมไหน ห้องไหน ใช้หน่วยกิตและเกณฑ์ใด

1. เปิด **รายวิชา → วิชาที่เปิดสอน → เพิ่ม**
2. เลือกวิชาเดิม หรือเลือก **เพิ่มวิชาใหม่ในหน้านี้** หากยังไม่มี
3. ถ้าเป็นวิชาใหม่ กรอกรหัสและชื่อวิชาตามช่องที่ระบุ
4. เลือกเทอมและติ๊กห้องที่จะเปิดสอน เลือกหลายห้องได้ในครั้งเดียว
5. กำหนดรูปแบบการให้ผล คะแนนเต็ม หน่วยกิต และเกณฑ์ตามหลักสูตรจริง
6. สำหรับวิชาเกรดตัวเลข ตรวจว่าต้องนำมาคำนวณ GPA หรือไม่
7. สำหรับผ่าน/ไม่ผ่าน เลือกว่าครูจะเลือกผลเอง หรือใช้คะแนนคำนวณผ่านตามเกณฑ์
8. ตรวจรายการแล้วกดบันทึกครั้งเดียว จากนั้นมอบหมายวิชาให้ครู

**หน่วยกิตสำคัญ:** ถ้าเอกสารต้นทางไม่มีหน่วยกิต ให้ตรวจหลักสูตรก่อนกรอก อย่าเดาตัวเลขเพื่อให้ GPA แสดง การแก้หน่วยกิตตั้งต้นในทะเบียนวิชาไม่เปลี่ยนค่าของวิชาที่เปิดสอนไปแล้วโดยอัตโนมัติ

วิชาเดียวกันในต่างห้องเป็นคนละรายการเปิดสอน ต้องตรวจรายการที่กำลังแก้หรือลบให้ถูกห้องและเทอม

### 7. จัดการเกณฑ์การตัดเกรด

1. เปิด **เกณฑ์การตัดเกรด**
2. ตรวจชื่อเกณฑ์และตารางคะแนนขั้นต่ำกับแต้มเกรด
3. ใช้เกณฑ์ที่ตรงกับหลักสูตรของโรงเรียน อย่าปรับเพื่อทดลองกับวิชาที่ใช้จริง
4. ถ้าเกณฑ์ถูกนำไปใช้แล้ว ระบบอาจล็อกการแก้ไข ให้ใช้ **สร้างรุ่นใหม่** แล้วเลือกเกณฑ์รุ่นใหม่กับรายการที่ต้องการ

การมีเกณฑ์รุ่นใหม่ไม่ได้เปลี่ยนวิชาเดิมหรือเกรดเก่าให้ใช้รุ่นใหม่เอง ต้องตรวจรายการเปิดสอนที่เกี่ยวข้อง

### 8. เชิญครูสมัครบัญชี

1. กด **เชิญครู** ที่แถบด้านบน หรือเปิดส่วนเชิญครูในการตั้งค่า
2. ระบุจำนวนวันที่รหัสใช้ได้ และจำนวนบัญชีที่สมัครได้
3. กดสร้างรหัสเชิญ อ่านและยืนยันข้อความที่แจ้ง รหัสใหม่ยกเลิกรหัสเดิม
4. ส่งลิงก์สมัครและรหัสให้ครูที่ต้องการเป็นการส่วนตัว
5. หลังครูสมัคร ให้เปิด **บัญชีครู** เพื่อตรวจชื่อและชื่อบัญชี
6. มอบหมายสิทธิ์ในขั้นตอนถัดไป ครูใหม่จะยังไม่เห็นข้อมูลนักเรียนก่อนมอบหมาย

รหัสเชิญมีวันหมดอายุและจำนวนครั้งใช้งาน ไม่ใช่รหัสผ่าน หากไม่ต้องการให้สมัครเพิ่ม ให้กดปิดการสมัครด้วยรหัสปัจจุบัน

### 9. มอบหมายรายวิชาและครูประจำชั้น

1. เลือกภาคเรียนด้านบน
2. เปิด **มอบหมายวิชาให้ครู** และเลือกครู
3. ส่วน **ครูประจำชั้น** ติ๊กห้องที่ครูดูแลในเทอมนี้ ครูจะดูนักเรียนและทุกวิชาของห้องนั้นได้ แต่แก้เกรดได้เฉพาะวิชาที่มอบหมายให้สอน
4. ส่วน **วิชาที่มอบหมายเพิ่มเติม** ติ๊กวิชา/ห้องที่ครูสอนเพิ่มเติม
5. การติ๊กแต่ละรายการบันทึกทันที รอให้รายการหยุดกำลังทำงานก่อนเปลี่ยนรายการ
6. ให้ครูรีเฟรชหน้าหรือเปิดหน้าภาพรวม เพื่อตรวจว่ารายวิชาและห้องแสดงถูกต้อง

นำเครื่องหมายออกเพื่อเพิกถอนสิทธิ์ มอบหมายห้องประจำชั้นใหม่เมื่อเปลี่ยนเทอม ไม่ใช้การแก้ชื่อห้องแทนการมอบหมาย

### 10. แก้ข้อมูลบัญชีครูและลบบัญชีทดลอง

**แก้ข้อมูล:** เปิด **บัญชีครู** → ค้นหาชื่อไทย ชื่ออังกฤษ หรือชื่อบัญชี → กด **แก้ไข** → เพิ่มชื่อไทยให้บัญชีเก่าหรือแก้ข้อมูลที่อนุญาต → บันทึก

ชื่อบัญชีเข้าสู่ระบบและรหัสผ่านเดิมไม่เปลี่ยนเพราะเพิ่มชื่อไทย หากระบบแจ้งว่าบัญชีถูกแก้ไขแล้ว ให้เปิดหน้าต่างแก้ไขใหม่ก่อนบันทึก

**ลบบัญชีทดลอง:** ตรวจว่ากำลังเลือกบัญชีครูที่ไม่ต้องใช้อีกแล้ว → กด **ลบบัญชีถาวร** → อ่านขอบเขตและยืนยัน

การลบบัญชีครูลบการเข้าสู่ระบบ โปรไฟล์ รูป ข้อเสนอแนะ และการมอบหมายของครูคนนั้น ไม่มีสำเนาบัญชีให้กู้คืน แต่ผลการเรียนของนักเรียนยังอยู่ ไม่สามารถใช้หน้าจอนี้ลบบัญชีผู้ดูแล/Developer หรือบัญชีที่กำลังใช้งานเอง

### 11. ปิดใช้งาน จัดเก็บ ลบถาวร และล้างคะแนน

| การทำงาน  | ผลที่เกิดขึ้น                                                            |
| --------- | ------------------------------------------------------------------------ |
| ปิดใช้งาน | เปลี่ยนสถานะของรายการ ข้อมูลและประวัติยังอยู่                            |
| จัดเก็บ   | เก็บรายการพร้อมประวัติ และมีคำสั่งนำกลับมาใช้งาน                         |
| ลบถาวร    | ลบจริงพร้อมข้อมูลที่เกี่ยวข้องตามขอบเขตในกล่องยืนยัน กู้คืนจากเว็บไม่ได้ |
| ล้างเกรด  | ลบคะแนนในขอบเขตที่เลือก แต่ไม่ใช่การลบตัวนักเรียน                        |

ขอบเขตที่ต้องอ่านก่อนลบ:

- **นักเรียน:** ลบตัวนักเรียน การลงทะเบียนทุกเทอม และเกรดทั้งหมดของนักเรียน
- **ทะเบียนวิชา:** ลบวิชาที่เปิดสอนของวิชานั้นและเกรดที่เกี่ยวข้อง
- **วิชาที่เปิดสอน:** ลบรายการของห้อง/เทอมนั้นและผลที่เกี่ยวข้อง รวมผลที่ประกาศแล้ว
- **ห้อง/ภาคเรียน:** ลบการลงทะเบียน รายการเปิดสอน และคะแนนที่เกี่ยวข้องตามขอบเขต แต่ไม่ใช่การลบข้อมูลตัวนักเรียนกลางทั้งหมด
- **เกณฑ์การตัดเกรด:** อาจลบรายการเปิดสอนและคะแนนที่อ้างอิงเกณฑ์นั้น ต้องอ่านกล่องยืนยันอย่างละเอียด

ในการตั้งค่ามี **พื้นที่อันตราย: ล้างคะแนนทั้งภาคเรียน** ซึ่งต้องยืนยันรหัสผ่าน ข้อความยืนยัน และยืนยันครั้งสุดท้าย ไม่ใช้ส่วนนี้สำหรับการทดสอบครั้งแรก เพราะลบทั้งคะแนนร่างและคะแนนประกาศของเทอมที่เลือก ให้ทดลองกับข้อมูลจำลองที่แยกไว้เท่านั้น

### 12. ตรวจประวัติและรับข้อเสนอแนะ

- เปิด **ประวัติการเปลี่ยนแปลง** เพื่อตรวจการเพิ่ม แก้ไข ประกาศ และลบข้อมูลตามที่ระบบบันทึก
- เปิด **แจ้งปัญหา / เสนอแนะ** เพื่ออ่านและปรับสถานะเรื่องที่ครูส่งมา
- เมื่อรับรายงานปัญหา ให้จดหน้า ภาคเรียน บัญชี/บทบาท ขั้นตอน และข้อความแจ้งเตือน โดยไม่เผยแพร่ข้อมูลนักเรียนหรือรหัสผ่าน

## นักเรียนเข้าสู่ระบบอย่างไร

1. ครูเปิดโปรไฟล์นักเรียนในภาคเรียนที่ดูแล กด **ตั้ง / เปลี่ยน PIN** ตั้ง PIN ตัวเลข 6–12 หลัก และยืนยันทั้งสองช่อง
2. แจ้งรหัสนักเรียน **5 หลัก** และ PIN เป็นส่วนตัว รหัสที่ขึ้นต้นด้วย 0 ต้องใส่ครบ ห้ามเผยแพร่ PIN ใน GitHub
3. นักเรียนเปิด [Login นักเรียน](https://school-ledger-beta.vercel.app/student/login) ใส่รหัสและ PIN
4. เลือกเทอมเพื่อดูผลที่ประกาศแล้ว คะแนนฉบับร่างไม่แสดง GPA ใช้เฉพาะวิชาตัวเลขที่มีหน่วยกิตและนำมาคำนวณ
5. เมื่อครูแก้รหัสนักเรียน ใช้รหัสใหม่ Login ได้ทันที PIN เดิมยังใช้ได้จนกว่าจะเปลี่ยน PIN
6. หากลืม PIN ให้ติดต่อครูหรือผู้ดูแล เมื่อตั้ง PIN ใหม่ Session นักเรียนเดิมทั้งหมดถูกยกเลิก
7. ออกจากระบบหลังใช้เครื่องร่วมกัน นักเรียนไม่มีสิทธิ์เปิดหน้า/API ของครู

### Theme และความสะดวกใหม่

ตั้งค่า → **Theme ส่วนตัว** เลือก Light/Dark/ตามระบบ ชุดสี หรือปรับสีเองได้ทันที เลือก Classic, Glassmorphism หรือ Neobrutalism มีผลเฉพาะเบราว์เซอร์นี้ ปุ่มใช้ Theme ของโรงเรียนคืนค่าเฉพาะชุดสี ส่วนหน้าตาเลือก Classic เพื่อคืนค่า

ครูประจำชั้นมีเมนู **ห้องประจำชั้น** สำหรับดูรายชื่อ GPA และความคืบหน้าทุกรายวิชา ผู้ดูแลกดชื่อครูใน **บัญชีครู** เพื่อดูโปรไฟล์และห้องประจำชั้น ประวัติแสดงชื่อผู้ดำเนินการ และโปรไฟล์นักเรียนแสดงกิจกรรมล่าสุดให้ผู้ดูแล

ปุ่ม **Support me** ยังไม่รับชำระเงิน ต้องตั้งลิงก์ Stripe สาธารณะก่อน อ่าน [ไฟล์และวิธีที่แก้เองได้ใน VSCode](docs/CUSTOMIZATION.md)

## รายการทดสอบสำหรับคุณครู

ใช้บัญชีครูจริงของผู้ทดสอบกับนักเรียน/วิชาจำลองที่ผู้ดูแลเตรียมให้

- [ ] สมัครด้วยรหัสเชิญและเก็บชื่อบัญชีไว้ จากนั้นเข้าสู่ระบบได้
- [ ] เลือกเทอมและเห็นวิชา/ห้องที่ผู้ดูแลมอบหมายถูกต้อง
- [ ] ค้นหานักเรียน เปิดโปรไฟล์ และดูข้อมูลได้
- [ ] แก้ชื่อ/เลขที่ของนักเรียนจำลอง แล้วเปิดใหม่พบค่าที่แก้
- [ ] กรอกตามวิชา บันทึก แล้วกลับมาเห็นคะแนนเดิม
- [ ] กรอกตามนักเรียน บันทึก และไปคนถัดไป/ย้อนกลับได้
- [ ] ทดลองผลผ่าน/ไม่ผ่าน หากวิชาจำลองตั้งรูปแบบนี้ไว้
- [ ] ประกาศแล้วแก้คะแนนไม่ได้; ยกเลิกประกาศแล้วแก้ บันทึก และประกาศใหม่ได้
- [ ] GPA ในรายชื่อ/โปรไฟล์สอดคล้องกัน และ Excel มีข้อมูลที่ต้องการ
- [ ] เปลี่ยนรูปโปรไฟล์ ภาษา และโหมดสว่าง/มืดได้
- [ ] ย่อ/ขยายเมนู ใช้ Dropdown และแจ้งปัญหาได้
- [ ] ออกจากระบบหลังเสร็จงาน

จดสิ่งที่หาไม่เจอหรือใช้แล้วไม่เข้าใจได้เลย โดยเฉพาะขั้นตอนที่ต้องถามผู้ดูแล เพื่อใช้ปรับปรุงรอบต่อไป
