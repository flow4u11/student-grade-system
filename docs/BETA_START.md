# เริ่มใช้ School Ledger beta.8

อ่าน [คู่มือภาษาไทยฉบับละเอียดสำหรับครูและผู้ดูแล](../README.md) ซึ่งมีขั้นตอนตั้งแต่เริ่มต้นและรายการสำหรับคุณครูทดสอบ

1. เปิด https://school-ledger-beta.vercel.app
2. ผู้ดูแลสร้างคำเชิญให้ครู แล้วครูสมัครจากลิงก์นั้น
3. ผู้ดูแลมอบหมายรายวิชา หรือกำหนดครูประจำชั้นในภาคเรียนที่เลือก
4. ครูกรอกผลตามรายวิชา หรือตามนักเรียน แล้วบันทึกฉบับร่าง
5. ตรวจผลและหน่วยกิตก่อนประกาศผล คะแนนที่ยังไม่ประกาศไม่ใช้คำนวณ GPA
6. หากต้องแก้ผลที่ประกาศ ให้ยกเลิกประกาศก่อนแก้และบันทึกใหม่

กดรูป/ชื่อด้านล่างเมนูเพื่อเปิดโปรไฟล์ คู่มือในเว็บอยู่ที่ https://school-ledger-beta.vercel.app/teacher/guide นักเรียนเข้าได้ที่ /student/login ด้วยรหัส 5 หลักและ PIN ที่ครูตั้งให้ ดูเฉพาะผลที่ประกาศแล้ว

ใช้ข้อมูลสมมติสำหรับลองเพิ่ม ล้างเกรด หรือลบข้อมูล การลบถาวรกู้คืนไม่ได้
